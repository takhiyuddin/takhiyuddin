## ✨ Key Features of This Web Design
*   **Vertical Timeline Navigation:** A sticky, interactive timeline that guides users through projects chronologically.
*   **Micro-interactions:** Spring-based hover effects on tech badges, timeline dots, and project images.
*   **Technical Accordions:** "Under-the-hood" details for each project (Architecture challenges, UI/UX focus, and Bug fixes logs) without cluttering the main UI.
*   **Fully Responsive:** Seamless layout adjustments from large desktop screens to small mobile devices.
*   **Performance Optimized:** Lightweight assets, CSS-based animations, and zero heavy JS frameworks for the core UI.
